## Application Layer

Responsible for system functions:

- FreeRTOS task management
- Battery monitoring logic
- Display update


## Interface Layer

Provides hardware abstraction:

Modules:

- BQ76920 interface
- CAN interface
- OLED interface


## HAL Layer

Generated by STM32CubeMX:

- GPIO
- I2C
- CAN
- UART


## Hardware

Target:

- STM32F103C8T6
- BQ76920
